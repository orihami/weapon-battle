# ウェポンバトル

武器を持ったボール同士が四角いフィールドの中で戦うシミュレーションです。
**攻撃が当たるたびに武器が強くなります**（剣はダメージ+1、短剣は回転が速くなる、など）。

- 公開ページ: https://orihami.github.io/weapon-battle/
- 武器は90種類: 剣 / 短剣 / 槍 / 斧 / ハンマー / 刀 / 鎌 / ムチ / 三叉槍 / 王笏 / ランス / 盾 / オーブ / オービタル / フレイル / 爆弾 / クロスボウ / 弓 / ポーション / 炎の杖 / 氷の杖 / ブーメラン / 素手 / トゲトゲ / クラスター / 地雷 / 隕石 / ミサイル / 手裏剣 / ハチの巣 / ガトリング / 雷 / ノコギリ / 火炎放射 / 毒ガス / 剣の嵐 / ブラックホール / 花火 / レーザー / スライム / 竜巻 / ヨーヨー / コウモリ / 跳弾 / 大剣 / ロケット / 音波 / 雪玉 / 分身 / 呪いの人形 / 吹雪 / フック / 毒ヘビ / 投げナイフ / ピコハン / サイコロ / 槍投げ / ドリル / 魔導書 / 水鉄砲 / 鎖鎌 / 鏡 / くっつき爆弾 / 蜘蛛の巣 / 時計 / ツタ / リボルバー / サメ / ものまね / カウンター / 重力反転 / 光の剣 / ドローン / 地震 / 不死鳥 / 磁石 / 流れ星 / 斧投げ / 弾幕 / 鉄球 / 雷雲 / 巨大化 / 吸命の牙 / 霊剣 / 溶岩 / 歯車 / 鎌鼬 / バンパー / プリズム / ゴースト
- 爆弾のように「当てるほど数が増えて、終盤にドパッと決まる」ローグライク風の成長をする武器が多め

## 遊び方

1. 左右の武器ボタンで武器を選ぶ（「🎲 左だけ / 両方 / 右だけ」でおまかせ。選択画面の「ランダムにおまかせ」でも片方だけ変えられる）
2. 「スタート」で対戦開始。×1 / ×2 / ×4 で速さを変えられる
3. 「📺 連続観戦」でランダムな対戦を自動で流し続ける。「🔗 この対戦を共有」で今の組み合わせのURLを送れる
4. 「⚔ チャレンジ」は左の武器で連戦するローグライクモード。勝つたびに強化を1つ選び、敵もだんだん強くなる
5. 「🏆 トーナメント」で8人か16人の勝ち抜き戦を自動で進められる
6. 下の「武器ずかん」には各武器の成長のしかたと、今までの勝敗が出る（「勝率順」にするとランキング）

## 開発

```sh
npm install
npm test          # ユニットテスト
npm run e2e       # ブラウザテスト
npm run balance   # 総当たりの勝率表
npm run serve     # http://localhost:8080 で確認
```
