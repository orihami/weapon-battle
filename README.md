**攻撃が当たるたびに武器が強くなります**（剣はダメージ+1、短剣は回転が速くなる、など）。

## 遊び方

ホーム画面で遊び方を選び、準備画面で武器を決めて「バトル開始！」。

- **⚔️ 1対1**: 2つの武器で対戦。武器をタップすると選ぶ画面(名前でさがす・近接/飛び道具/特殊で絞り込み)、🎲 でその人だけランダム、⇄ で入れ替え
- **💥 バトルロイヤル**: 3〜4人が広いフィールドで同時に戦う。それぞれ一番近い相手をねらい、最後に残った1人の勝ち
- **🃏 ラウンズ**: 2〜4人(人とCPUを混ぜられる)が同時に戦う。勝った人に★、負けた人は全員スキルカードを選んで強くなる(3回目ごとは大進化で2枚)。先に決めた数だけ勝った人が優勝。1台を交代で操作
- **📡 みんなでバトル(オンライン)**: 別々のスマホで同じ部屋(4文字のコード)に入り、それぞれ武器を選ぶ。部屋を作った人が始めると、全員のスマホで同じ試合が流れる。サーバーが必要(`server/README.md`)
- 武器には**ジャンル**(⚔️刃・🔨打撃・🏹射撃・✨魔法・💥爆発・🌪️自然・👻召喚・🐾生き物・👊体術・🎩トリック)と、育ち方の印(📈大器晩成=数値どおりに伸びて後半に化ける / 🌱進化=姿が変わる)がある
- **🐉 ボス・レイド**: 2〜4人が協力して巨大なボスと戦う(仲間には攻撃が当たらない)。ボスは12種類(スライムキング・機械要塞・竜王・雷の巨人・影の忍者王・氷の女王・毒の大蛇・クラーケン・砂の大ミミズ・双子の鬼・隕石の神、8レベルごとに魔王)で、HPが減ると第2形態→怒り(怒ると倒れた仲間が1度だけ復活)。チームの武器の組み合わせで**コンビ技**(前衛と後衛・炎の仲間・双子など)。勝つと全員がカードを1枚選び、3体ごとに宝箱(4枚から2枚)。毎回の与ダメージランキングとMVP。強さは かんたん/ふつう/むずかしい
- **🗡️ チャレンジ**: 1人用ローグライク。勝つたびにスキルカード、5ステージごとにボス、倒すと大進化
- **🏆 トーナメント**: 8人か16人の勝ち抜き戦を自動で進める
- **📺 連続観戦**: 1対1や3〜4人のランダムな対戦を流し続ける
- **📖 武器ずかん**: 各武器の成長のしかたと戦績(勝率順にするとランキング)。タップでその武器の1対1へ

バトル画面の上には各プレイヤーのHP・能力値・スキル、下には 一時停止 / 速さ(×1・×2・×4) / 共有。「←」かスマホの「戻る」で前の画面へ。

## 開発

```sh
npm install
npm test          # ユニットテスト
npm run e2e       # ブラウザテスト
npm run balance   # 総当たりの勝率表
npm run serve     # http://localhost:8080 で確認
```
