# ウェポンバトル

武器を持ったボール同士が四角いフィールドの中で戦うシミュレーションです。
**攻撃が当たるたびに武器が強くなります**（剣はダメージ+1、短剣は回転が速くなる、など）。

- 公開ページ: https://orihami.github.io/weapon-battle/
- 武器は60種類: 剣 / 短剣 / 槍 / 斧 / ハンマー / 刀 / 鎌 / ムチ / 三叉槍 / 王笏 / ランス / 盾 / オーブ / オービタル / フレイル / 爆弾 / クロスボウ / 弓 / ポーション / 炎の杖 / 氷の杖 / ブーメラン / 素手 / トゲトゲ / クラスター / 地雷 / 隕石 / ミサイル / 手裏剣 / ハチの巣 / ガトリング / 雷 / ノコギリ / 火炎放射 / 毒ガス / 剣の嵐 / ブラックホール / 花火 / レーザー / スライム / 竜巻 / ヨーヨー / コウモリ / 跳弾 / 大剣 / ロケット / 音波 / 雪玉 / 分身 / 呪いの人形 / 吹雪 / フック / 毒ヘビ / 投げナイフ / ピコハン / サイコロ / 槍投げ / ドリル / 魔導書 / 水鉄砲
- 爆弾のように「当てるほど数が増えて、終盤にドパッと決まる」ローグライク風の成長をする武器が多め

## 遊び方

1. 左右の武器ボタンで武器を選ぶ（「🎲 左だけ / 両方 / 右だけ」でおまかせ。選択画面の「ランダムにおまかせ」でも片方だけ変えられる）
2. 「スタート」で対戦開始。×1 / ×2 / ×4 で速さを変えられる
3. 下の「武器ずかん」には各武器の成長のしかたと、今までの勝敗が出る

## 開発

```sh
npm install
npm test          # ユニットテスト
npm run e2e       # ブラウザテスト
npm run balance   # 総当たりの勝率表
npm run serve     # http://localhost:8080 で確認
```
